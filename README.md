# Baby Day

A shared, low-friction newborn care companion for two parents.

The point is not another complicated baby tracker. It is a **shared memory and handover layer**: either parent logs what happened in a few seconds, the other parent sees it, and nobody has to ask whether the baby already fed.

This repository is just getting started. Product thinking lives in `docs/`.

Planning. No app yet. The first useful version should be a private family PWA: quick logging (including breast side and live timers), today timeline, handover, offline queue, and sync between two phones.
